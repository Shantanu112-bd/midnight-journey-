# ProofWork — Privacy Model Documentation

## Privacy Assurance Matrix

| Element | Public Ledger State | Private Witness Payload | Observer Capability |
| :--- | :--- | :--- | :--- |
| **Agreement** | 256-bit Hash | Salary, Terms, Names | Can verify existence; cannot read terms |
| **Complaint** | Incremented Counter | Whistleblower identity & text | Can count complaints; cannot identify sender |
| **Vote** | Incremented Vote Total | Employee choice (YES/NO) | Can see total count; cannot link vote to voter |
| **Survey** | Incremented Survey Count | Anonymous feedback text | Can see submission count; cannot leak feedback identity |
